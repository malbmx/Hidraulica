# Hidráulica aplicada a la Agronomía

Libro académico web de Miguel Armando López Beltrán (2026), dirigido a estudiantes que comienzan a estudiar hidráulica con aplicaciones agrícolas.

## Organización del sitio

- `docs/index.html`: índice general del libro; se añade una tarjeta únicamente cuando una unidad está disponible.
- `docs/unidad-1/index.html`: portada de Hidrostática, con temas 1.1–1.4 en páginas independientes.
- `docs/unidad-2/index.html`: portada de Hidrocinemática, con temas 2.1–2.4 en páginas independientes.
- `docs/unidad-3/index.html`: portada de Hidrodinámica, con temas 3.1–3.5 y tres exploradores interactivos.
- `docs/assets/`: imágenes compartidas por el libro.

El sitio es material teórico-práctico autónomo. Las actividades web son ejercicios de estudio, no instrucciones de una plataforma educativa. Las unidades posteriores deben seguir la misma estructura: portada de unidad, páginas por subtema, diagramas, derivaciones, ejemplos, práctica y fuentes verificables.

Convención numérica para todas las unidades: **punto decimal** (`0.50 m/s`) y millares con espacio o sin agrupador (`35 000 Pa` o `35000 Pa`). Revisar también las cifras de diagramas, tablas, texto alternativo y soluciones.

La publicación se realiza desde `docs/` en la rama `main`. No se incluyen claves docentes, rúbricas reservadas, datos personales ni archivos de calificaciones.
