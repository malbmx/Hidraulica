3.4 · Ecuación de Bernoulli

Pregunta de riego: ¿cuánta energía necesita una bomba para elevar agua y mantener presión útil en una red?

Bernoulli integra la ecuación de Euler para relacionar energía mecánica entre secciones. La forma ampliada permite incluir bomba, extracción de energía y una pérdida de carga proporcionada:

H₁ + hp − ht − hL = H₂,   H = z + p/(ρg) + V²/(2g)

zCarga de posición respecto al plano elegido, m.
p/(ρg)Carga de presión manométrica o absoluta, sin mezclarlas, m.
V²/(2g)Carga de velocidad, m.
hp, hLCarga añadida por bomba y pérdida, m.

Ejemplo resuelto · descarga desde un depósito elevado

  1. Puntos: 1 en la superficie libre, z₁ = 4.5 m; 2 en la salida, z₂ = 0.5 m. Ambas presiones manométricas son cero y V₁ ≈ 0.
  2. Se proporciona hL = 0.8 m. No hay bomba: hp = 0.
  3. Bernoulli: z₁ = z₂ + V₂²/(2g) + hL.
  4. V₂ = √[2g(z₁ − z₂ − hL)] = √[2(9.81)(3.2)] = 7.92 m/s.
  5. Para D = 40 mm, A = 0.001257 m² y Q = AV = 0.00995 m³/s = 9.95 L/s.
  6. Interpretación: el valor es didáctico; una descarga real requiere pérdidas calculadas o medidas y revisión de condiciones de operación.

Ejemplo 2 · carga de bomba para aspersión

  1. Datos didácticos: depósito abierto en z₁ = 0; aspersor en z₂ = 18 m; presión requerida p₂/(ρg) = 25 m; V₂ = 1.5 m/s; hL = 4.0 m.
  2. hp = 18 + 25 + 1.5²/(2×9.81) + 4.0 = 47.1 m.
  3. Si Q = 8.0 L/s y η = 0.70, potencia hidráulica de entrada aproximada: P = ρgQhp/η = 5.28 kW.
  4. Interpretación: es una estimación de selección; debe contrastarse con curva de bomba, variación de nivel, eficiencia y pérdidas reales.

Explorador · intercambio de cargas

Varía elevación y pérdida. Observa que si hL consume toda la diferencia de nivel, el modelo ya no dispone de carga para velocidad.

Ejercicio agrícola

Un tanque abierto alimenta un hidrante 12 m más alto. En el hidrante se requieren 20 m de carga de presión, V = 1.2 m/s y se proporcionan 3.5 m de pérdidas. Calcula la carga mínima de bomba.

Comprobación

hp = 12 + 20 + 1.2²/(2×9.81) + 3.5 = 35.57 m ≈ 35.6 m.
